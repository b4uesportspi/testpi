# Changelog

All notable changes to the B4U Esports email system will be documented in this file.

## [2025-10-23]

### Changed
- Reduced B4U Esports logo size from 200x67 pixels to 120x40 pixels in all email templates
- Added professional legal disclaimer in italics to all email templates (purchase confirmation, profile update, admin notification)
- Updated username styling to purple (#7c3aed) with bold font weight in all email templates
- Updated package/game name styling to blue (#1e3a8a) with bold font weight in all email templates
- Added game-specific logos (PUBG, MLBB, Clash of Clans) to profile update emails
- Added Pi Network trademark symbol (™) to footer text

### Fixed
- Improved visual consistency across all email templates
- Enhanced email professionalism with legal disclaimer
- Better visual distinction for important information (usernames, packages)

## [2025-10-20]

### Added
- Initial implementation of email service with three email types:
  - Purchase confirmation emails
  - Profile update emails
  - Admin purchase notifications
- Responsive HTML email templates
- SMTP integration with Hostinger
- Environment variable configuration
- Error handling and logging

### Changed
- Configured email branding with B4U Esports colors and logos
- Implemented responsive design for all email templates
- Added social media links to email footers
- Integrated Pi Network branding in email footers
